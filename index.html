Senior Heuristics · Triage Tree

Senior Loop Failure Modes & Diagnostic Resolutions

Antipattern 01
Ping-Pong Thrash
Agent alternates cyclically between Approach A and Approach B, breaking tests alternately in a loop.
The Fix
Inject git diff of last 2 failed attempts into failure report so agent explicitly sees past dead-ends.
Antipattern 02
Flaky Test Poisoning
Tests pass or fail intermittently across iterations due to unmocked system clocks or unseeded database ordering.
The Fix
Freeze time with Carbon::setTestNow(), seed random number generators, and isolate in-memory DB transactions.
Antipattern 03
Specification Vacuum
Vague prompts pass shallow assertions but violate actual business contracts and client API schemas.
The Fix
Pre-write failing Pest tests & JSON contracts before launching the implementation loop (True TDD).
